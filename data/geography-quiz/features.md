# Suggested features: geography-quiz
- Modes: daily 10, endless, timed blitz, continent packs, "hard only".
- Map-click with distance scoring (km from target, scaled by tolerance_km) and an answer reveal line.
- Flags rendered from ISO code via an open flag set (e.g. flag-icons, MIT); text-description mode for accessibility.
- Spaced repetition per question id; weak-area dashboard by type/continent.
- "Learn more" drawer showing the Factbook explanation and the disputed-status note.
- Two-player pass-and-play and shareable result card (no account needed).
- Data refresh job: re-run tools/build.py on new Factbook releases and diff answers.
